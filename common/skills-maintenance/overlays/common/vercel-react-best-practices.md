# `vercel-react-best-practices` semantic overlay

## Preserve

- Track the complete upstream React best-practices skill and all rule files.
- Keep the narrowed `description` in `SKILL.md` frontmatter so the skill triggers only when the user explicitly signals performance matters, not on routine React edits.
- In the generated root `AGENTS.md`, keep links to individual rules resolvable by prefixing them with `rules/` when upstream emits root-relative links to files stored in that directory.

## Acceptance

The installed rule set otherwise matches upstream, and every local Markdown link resolves.
